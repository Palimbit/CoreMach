# BluMach interface icons

Author and copyright: rtzor, 2026. Distributed under
`GPL-2.0-or-later` as part of BluMach.

The SVG files are the editable sources for the BluMach interface icon set. The
24 × 24 and 48 × 48 PNG files are raster derivatives included for Qt builds that
do not render SVG icons reliably at runtime.

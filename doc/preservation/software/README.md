# Software catalogue placeholder

No software catalogue is part of the current PCS/Dario preservation work.

A future catalogue may use one metadata record per release with fields for
publisher, product, version, language, media geometry, hashes, provenance,
malware status and machine compatibility. It must not place disk images,
executables or proprietary archives in this repository.

Software metadata must remain separate from:

- machine identity and hardware implementation;
- firmware metadata;
- diagnostic results produced during emulator validation.

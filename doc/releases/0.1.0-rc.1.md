# BluMach 0.1.0-rc.1 private validation record

This candidate freezes the current product as a functional reference before
the portable engine is developed. It is a private validation build, not a
public release or a compatibility promise.

## Immutable build identity

- Version: `BluMach 0.1.0-rc.1`
- Source branch: `release/0.1.0-rc.1`
- Source commit: recorded by `tools/rc_manifest.py` in the local build output
- Target: Windows x86-64, Qt 6, UCRT64
- Firmware or guest media distributed: no
- Package manifest: `BluMach-0.1.0-rc.1-Windows-x86_64.manifest.json`
- Archive checksum: `BluMach-0.1.0-rc.1-Windows-x86_64.zip.sha256`

Create the candidate from a clean committed checkout:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-private-rc.ps1
```

The package, manifest and checksum are written below the ignored `dist/`
directory. The build stops if tracked files are modified, the executable does
not report the exact candidate version, the package exceeds its size budget,
or a likely ROM, BIOS or guest-media file is present.
